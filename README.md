🕵️ Find the Spy

A simple offline multiplayer social deduction game.

Find the Spy is an offline multiplayer game where players try to identify the hidden spy through social interaction, discussion, and deduction.

🎮 About the Game

Find the Spy is designed for people who enjoy social deduction games. It brings players together for an interactive guessing experience without requiring an internet connection.

✨ Features

- Offline gameplay
- Multiplayer experience
- Social deduction gameplay
- Lightweight Android application
- Simple and user-friendly interface
